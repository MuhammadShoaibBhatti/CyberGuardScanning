# CyberGuardScanning
CyberGuard Lab is a Windows desktop app for ethical cybersecurity learning. It captures packet metadata, scans ports on private IPs, finds devices with ARP, and shows live charts and reports in a dark neon hacker-style UI. Built with Python, CustomTkinter, and Scapy. Local only, no payloads or passwords. Use only on networks you own or may test.
